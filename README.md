# React Learning Journey

A 60-day roadmap covering React, Node.js, Express, PostgreSQL, and Frappe.

## Week 1 — React Core

### Concepts Covered

- Components and Props
- useState — Counter, Controlled Form with validation
- useEffect — API calls, Loading state
- Search Filter using .filter() and .map()
- Children prop — generic wrapper components

### Components Built

- ProfileCard — displays name, role, and skills
- SkillBadge — individual skill pill/badge
- Header — site navigation
- Card — generic wrapper using children prop
- Counter — increment and decrement with useState
- ContactForm — controlled inputs with basic validation
- UsersList — fetches real API data with search filter

## Tech Stack

- React 18
- Vite
- JavaScript (ES6+)
